# À propos de Trois d'un Coup

**Trois d'un Coup** est un puzzle de gemmes à échanger, développé par
**Geoffroy Streit** (alias **Hylst**).

## Le jeu

Le principe est connu : un plateau 8×8 de gemmes, échangez deux voisines pour aligner 3
pièces identiques ou plus. Chaque alignement de 4 crée une gemme rayée, un alignement de 5
crée un arc-en-ciel, et une forme en L ou en T crée une bombe. Les cascades s'enchaînent,
les combos multiplient le score, et le niveau grimpe.

« Trois d'un coup » joue sur le nom du genre (le « match 3 ») et sur l'expression « faire
d'une pierre deux coups » — ici, on en fait au moins trois.

- React 19, TypeScript 5.9 (strict), Tailwind CSS 4
- Vite 7, vite-plugin-singlefile
- Logique de jeu pure (`gameEngine.ts`), rendu React/SVG
- Web Audio API pour la musique et les effets
